### Supervised Learning · Employee Attrition Prediction

> BITS Pilani BS Data Science & AI · Supervised Learning

Trained and compared 5 classification models (Logistic Regression, Decision Tree, Random Forest, Bagging, XGBoost) on the IBM HR Analytics dataset to predict employee attrition. Selected Logistic Regression as the final model based on best F1-score (0.4384), best ROC-AUC (0.8079), and smallest train-test accuracy gap (0.0417), indicating the strongest generalization among all models tested.
